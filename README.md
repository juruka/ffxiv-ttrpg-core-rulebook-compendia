# FFXIV TTRPG Rulebook Compendia

A compendium module for FFXIV TTRPG that includes content from the Standard Rulebook and Stormblood expansion. This is intended to be used with [Valamyrr's FFXIV TTRPG system](https://github.com/Valamyrr/FFxivTTRPG).

This module supports the images supplied by the [FFXIV TTRPG Icons Pack](https://github.com/AxeBane/ffxiv-ttrpg-icons-pack), but you are welcome to use your own instead.

**For installation**, copy the following into Foundry VTT's manual install bar: ``https://raw.githubusercontent.com/juruka/ffxiv-ttrpg-core-rulebook-compendia/main/module.json``

## Translations

Compendium translations use Babele 2.9.1 or later and the FFXIV system's translation support. This module includes the Traditional Chinese (`zh-TW`) translation, including embedded actions, traits, effects, pets, journal pages, and automation labels. See [Translating the compendia](TRANSLATING.md) for export instructions, file locations, editable fields, entry keys, and testing.

## 使用繁體中文翻譯

1. 安裝並啟用 FFXIV 系統、Babele，以及本模組。
2. 在 Foundry VTT 的世界設定中，將語言設為 **繁體中文**（`zh-TW`）。
3. 重新載入頁面，開啟 **Axe's Compendium** 下的合集。
4. 將職業、技能、道具或寵物從合集拖曳到角色或場景中；新建立的文件會使用翻譯後的名稱與文字。

翻譯只覆蓋合集顯示內容，不會修改原始合集資料，也不會自動更新已經匯入角色的舊文件。若部分內容仍是英文，通常代表該項目尚未翻譯，或目前核心合集版本比翻譯檔更新；請確認模組、Babele 與 FFXIV 系統均已啟用後重新載入。
